# Northside Fitness Hub – Events & Updates

A small static page for the fictional Northside Fitness Hub gym. It shows:

- an announcements banner
- an opening-hours card
- a list of upcoming classes and workshops

Content is loaded from the JSON files in `data/`. The page uses plain HTML, CSS and JavaScript with no frameworks or external resources.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:8080.
